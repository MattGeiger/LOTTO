# Formatting Announcements

Announcements support **Markdown** — a simple way to add titles, bold, italics,
and lists without any special software. The announcement editor has buttons for
the common options, so you don't have to memorize anything; this guide is for
staff who'd like to type the formatting directly in **Edit Code** mode.

Tip: use the editor's **Live Preview** to see exactly how your announcement will
look before you save.

## Titles

Start a line with `##` and a space to make a title.

```
## Pantry closed Friday
```

## Bold

Wrap text in double asterisks.

```
We are **closed** on Friday.
```

We are **closed** on Friday.

## Italics

Wrap text in single underscores (or single asterisks).

```
Please arrive _before_ noon.
```

Please arrive _before_ noon.

## Underline

Underline uses an HTML tag, since Markdown has no underline of its own.

```
This is <u>important</u>.
```

## Bulleted lists

Start each line with a dash and a space.

```
- Canned goods
- Fresh produce
- Bread
```

- Canned goods
- Fresh produce
- Bread

## Numbered lists

Start each line with a number, a period, and a space.

```
1. Take a ticket
2. Watch the board
3. Come up when your number is called
```

1. Take a ticket
2. Watch the board
3. Come up when your number is called

## Links

Put the link text in square brackets and the address in parentheses.

```
See [today's hours](https://williamtemple.org).
```

See [today's hours](https://williamtemple.org).
